# 江湖行 · 武侠开放世界 RPG

基于 gocligames 引擎（纯 Go 标准库，跨平台）制作的大型终端武侠 RPG。

## 玩法

你是初出茅庐的江湖小虾米，从青州城拜师学艺开始，一步步成长为绝世高手，
挫败血月教颠覆武林的阴谋。

主线（6 步）：青州城拜师 → 黑风寨取密信 → 古墓寻天蚕神功 → 洛阳见捕头 → 天山顶决战血月教主

支线（3 个）：药铺急单（采灵芝）、洛阳乞酒（女儿红）、镖局押镖（护送镖车）

## 系统一览

- 双层地图：中原大地野外图 + 青州城/洛阳城/黑风寨/幽暗古墓/天山顶 5 张子地图，传送门互通
- 回合制战斗：多武功招式（连击/强攻/治疗/用毒）、防守、战斗用药、逃跑；Boss 不可逃
- 门派系统：少林/武当/丐帮三派拜师，各 3 门绝学
- 境界体系：初入江湖 → 三流 → 二流 → 一流 → 宗师 → 大宗师 → 绝世高手
- 装备系统：武器/护甲/饰品三槽，商店购买，怪物掉落（掉装备折银）
- 物品系统：金疮药/大还丹/内力丹 + 任务道具
- 商店/当铺/客栈/赌场（骰子押大小小游戏）
- 奇遇事件：老乞丐传功（五毒掌）/野狼袭击/拾获银两/血月线索
- 自动存档（jianghu_save.json）+ 江湖名人榜（jianghu_rank.json，Top10 战力榜）
- 通关后内容：血月余孽出没中原（更强野怪，可继续刷战力冲榜）

## 操作

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| E | 交互（对话/开箱/触发传送） |
| I | 背包（W/S 选择，E 使用） |
| F | 武功列表 |
| T | 任务日志 |
| B | 江湖名人榜 |
| H | 帮助 |
| 1 / 2 | 快捷服用金疮药 / 大还丹 |
| Q | 退出（自动存档） |

战斗：1-6 出招，D 防守，X/C 用药，Q 逃跑。

## 运行

```bash
cd gocligames
go run ./cmd/jianghu          # 或 ./bin/jianghu
```

AI 自动游玩（数值平衡自测 / 自动打榜）：

```bash
./bin/jianghu --bot
```

## 构建（三平台）

```bash
bash build.sh
```

## 代码结构

| 文件 | 内容 |
|------|------|
| main.go | 状态机/移动/存档/渲染/主循环 |
| world.go | 区域地图 + 对象生成 + 传送表 |
| data.go | 物品/装备/武功/门派/怪物/任务数据 |
| npc.go | NPC 对话/主线/支线/奇遇 |
| fight.go | 回合制战斗系统 |
| menu.go | 背包/装备/武功/任务/榜单/帮助界面 |
| shop.go | 商店/当铺/客栈/赌场 |
| bot.go | AI 自动玩家（--bot） |
| jianghu_test.go | 单元测试 + 地图连通性 + 主线通关模拟 |
